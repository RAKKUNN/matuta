# Matuta 1.2.0 — 모션과 촉각 다듬기

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 이 앱은 "편안하게 깨우기"를 표방하면서 그 성격이 소리에만 적용돼 있다. 화면과 촉각에도 같은 성격을 준다.

**Architecture:** 모션 어휘(지속시간, 감속 곡선, Reduce Motion 축약)를 `MatutaCore`의 순수 값으로 두고 테스트로 지킨다. 앱 레이어는 그 값을 읽어 쓰기만 한다. 이 저장소가 이미 쓰는 "판정은 코어, 실행은 앱" 구조를 모션에도 그대로 적용한다.

**Tech Stack:** Swift 6.3, SwiftUI, AppKit (`NSWindow.animator()`, `NSHapticFeedbackManager`), 기존 SwiftPM 구성 유지

## Global Constraints

- 배포 대상 macOS 14.0 이상, 비샌드박스, Developer ID 서명 + 공증
- 모든 사용자 노출 문자열은 `LocalizedText` 키를 거친다
- 각 태스크 종료 시 `swift build` 무경고, `swift test` 전부 통과

### 이 작업의 디자인 원칙

이 네 가지는 협상 대상이 아니다. 코드 리뷰에서 이걸 어기는 변경은 되돌린다.

1. **모션은 기능을 지연시키지 않는다.** 알람이 울릴 때 소리는 즉시 난다. 화면만 서서히 나타난다. 끌 때도 소리가 먼저 멈추고 화면이 나중에 사라진다. **반쯤 잠든 사람이 애니메이션을 기다리게 만들지 않는다.**
2. **Reduce Motion을 존중한다.** 시스템 설정이 켜져 있으면 모든 새 모션의 지속시간은 0이 된다. 기능은 그대로 동작한다.
3. **읽어야 할 것은 움직이지 않는다.** 시계 숫자, 알람 시각, 경고 문구에는 모션을 넣지 않는다. 움직이는 것은 배경·컨테이너·어포던스뿐이다.
4. **침대 옆에서 볼 것은 튀지 않는다.** 알람 발화 경로에는 스프링·바운스를 쓰지 않는다. 불투명도 위주의 감속 곡선만 쓴다. 호버 같은 낮 시간 상호작용에는 스프링을 써도 된다.

## 배경

현재 모션은 18곳뿐이고, 그마저 나이트스탠드와 시각 입력기에 몰려 있다. 정작 이 앱의 시그니처 순간에는 아무것도 없다.

| 지점 | 현재 | 문제 |
|---|---|---|
| 알람 발화 (오버레이 등장) | `makeKeyAndOrderFront` 하드컷 | **소리는 30초 페이드인, 화면은 순간 전환.** 앞뒤가 안 맞는다 |
| 알람 해제 (오버레이 퇴장) | `orderOut` 하드컷 | 눌렸는지 확인이 안 된다 |
| 목록 변화 | 애니메이션 없음 | `save()`가 시각순 정렬을 하므로 **편집하면 카드가 순간이동**한다 |
| 해제 어포던스 | 정적 | 반쯤 잠든 사람이 해야 할 유일한 행동인데 유도가 없다 |
| 촉각 | 전무 | 알람을 켜는 것은 신뢰를 맡기는 결정인데 아무 반응이 없다 |
| Reduce Motion | **지원 없음** | 접근성 설정을 무시하고 있다 |

```swift
import Foundation

/// 앱의 모션 어휘. 지속시간을 뷰마다 흩뿌리지 않고 여기 이름을 붙여 모은다.
///
/// 판정(Reduce Motion 이면 0)은 순수 함수이므로 테스트가 지킨다.
/// 시스템 설정을 읽는 일은 앱 레이어(`MotionEnvironment`)가 한다.
public enum Motion {

    public enum Role: CaseIterable, Sendable {
        /// 알람이 울리며 전체화면이 나타난다. 이 앱에서 가장 조심스러워야 할 순간.
        case alarmAppear
        /// 스페이스바로 알람을 껐다. 확인은 주되 기다리게 하지 않는다.
        case alarmDismiss
        /// 알람 추가·삭제·시각 변경에 따른 목록 재배치.
        case listChange
        /// "SPACE" 어포던스의 느린 호흡.
        case affordanceBreath
        case nightstandAppear
        case nightstandDismiss
    }

    /// 무언가를 끄는 모션의 상한. 이 위로 올라가면 사용자가 기다리게 된다.
    public static let dismissCeiling: Double = 0.3

    public static func duration(_ role: Role, reduceMotion: Bool) -> Double {
        guard !reduceMotion else { return 0 }

        switch role {
        case .alarmAppear:        return 0.45   // 소리 페이드인과 성격을 맞춘다
        case .alarmDismiss:       return 0.22
        case .listChange:         return 0.28
        case .affordanceBreath:   return 2.0    // 호흡. 빠르면 초조해 보인다
        case .nightstandAppear:   return 0.40
        case .nightstandDismiss:  return 0.22
        }
    }
}
```

```swift
    static func duration(_ role: Motion.Role) -> Double {
        Motion.duration(role, reduceMotion: reduceMotion)

}
```

```swift
    func hide(completion: (() -> Void)? = nil) {
        let closing = windows
        windows.removeAll()

        guard !closing.isEmpty else {
            completion?()
            return
        }

        let duration = MotionEnvironment.duration(.alarmDismiss)
        NSAnimationContext.runAnimationGroup { context in
            context.duration = duration
            context.timingFunction = CAMediaTimingFunction(name: .easeIn)
            for window in closing {
                window.animator().alphaValue = 0
            }
        } completionHandler: {
            for window in closing {
                window.orderOut(nil)
            }
            completion?()
        }
    }
```

## Task 3: 목록이 움직이게

`ForEach(model.alarms)` 에 애니메이션이 없다. 그런데 `save()` 는 시각순으로 정렬한다.


## Task 5: 알람을 켜는 순간의 촉각

앱 전체에 햅틱이 하나도 없다. 아무 데나 넣자는 것이 아니라 **딱 한 군데** 넣는다.

- [ ] **Step 1: 래퍼 작성**

```swift
import AppKit

/// 촉각 피드백. Force Touch 트랙패드에서만 실제로 느껴지고,
/// 그 외 기기에서는 조용히 아무 일도 하지 않는다.
@MainActor
enum Haptics {
    /// 되돌리기 어렵거나 무게가 있는 결정을 확인해 준다.
    ///
    /// 이 앱에서는 알람을 켜는 순간에만 쓴다. 모든 상호작용에 반응을 주면
    /// 아무것도 강조되지 않는다.
    static func commit() {
        NSHapticFeedbackManager.defaultPerformer.perform(

        )
    }
}
```
