# Matuta

macOS 전용 알람앱. 기본 시계 앱의 알람을 계승하되, **어떤 음악 소스로든 깨울 수 있고 절대 안 울리는 일이 없는** 것을 목표로 한다.

> *마테르 마투타*(Mater Matuta)는 로마 신화의 새벽과 아침빛의 여신이다. 라틴어 *matutinus*(아침의)와 프랑스어 *matin*이 이 어근에서 나왔다.

현재 이 저장소에는 **설계 문서만** 들어 있다. 코드는 아직 없다.

## 왜 만드는가

macOS 기본 시계 앱의 알람에는 세 가지 구멍이 있다.

- 절전에 들어가면 아예 안 울린다
- 내장 벨소리 몇 개뿐, 내 음악을 못 넣는다
- 볼륨 페이드인·스누즈 길이·출력 기기 제어가 없다

그리고 기존 상용 앱들은 전부 **"일단 울리기만 하면 끝"을 가정**한다. Mac은 아이폰과 달리 출력이 블루투스 이어폰으로 가 있거나, 볼륨이 0이거나, 뮤트일 수 있는데도 그렇다. Matuta의 차별점은 여기다 — **울리지 않을 경우를 미리 제거하는 것.**

## 개발 단계

| 단계 | 내용 | 상태 |
|---|---|---|
| 0. 스파이크 | 절전 깨우기 권한 검증 | 계획 완료 |
| 1. 뼈대 | 알람 CRUD, 스케줄러, 오버레이, 내장 사운드 | 계획 완료 |
| 2. 소스 | 소스 6종, 옴니박스, 폴백 체인 | 계획 미작성 |
| 3. 신뢰성 | AudioGuard, 프리플라이트, 나이트스탠드, 절전 깨우기 | 계획 미작성 |

1단계가 끝나면 이미 매일 쓸 수 있는 알람앱이 된다. 2·3단계 계획은 1단계를 며칠 실제로 써본 뒤에 쓴다.

## 정해둔 것

- **배포:** Developer ID 서명 + 공증, 비샌드박스, 직접 배포 (무료/오픈소스). App Store는 샌드박스가 전원 이벤트 API를 막아서 택하지 않았다
- **해제:** 스페이스바 한 번. 스누즈는 일부러 마우스 클릭으로만
- **설정:** 알람별 동작 설정은 볼륨·페이드인·스누즈 셋뿐. 신뢰성 관련은 전부 앱이 알아서 한다
- **기술:** Swift 6, SwiftUI, SwiftPM (Xcode 프로젝트 파일 없음)

## 하지 않기로 한 것

미션형 해제(수학 문제·사진 촬영), 범용 아침 자동화 런처, iOS 앱과 동기화, 클록 테마 다양화.
